# Historial de publicación

## v1.0.0 — 2026-11-19 — Edición definitiva de GitHub

- Publicación basada en la **v0.3.7**: mismas mecánicas, físicas, sprites, música y configuraciones.
- Carátula oficial y **relato original** de Tony C. Ware incorporados.
- Manual ilustrado y atlas visual con memoria técnica; recursos reales, sin capturas inventadas.
- README y documentación de publicación unificados, eliminando instrucciones contradictorias de versiones antiguas.
- El número de versión visible se actualiza a **1.0.0**.
- Se conservan los scripts para AppImage Linux x86_64 y EXE Windows y las pruebas automáticas.

## Referencia de la versión de juego 0.3.7

- Portales y arcos de energía más visibles, destellos estelares y fondos HD oscurecidos suavemente.
- Plataformas arcade reforzadas y suelo visual bajo Dom, sin sombras de pulpos.
- Sistema de bonus revisado; doble látigo 10 s; efectos temporales limitados a una fase.
- Cinco mundos de cinco pantallas, música original, menús, mandos, SMILEYS y explosión de Dom.

Esta edición NO incluye ejecutables AppImage o EXE previamente compilados; para generarlos, utiliza los scripts documentados y verifica el resultado en tu sistema.
